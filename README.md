# Data Analyzer (Streamlit)

Upload a CSV or Excel file and explore it: overview, column info, statistics,
KPIs, multi-column comparison, charts and correlation.

## Run
    pip install -r requirements.txt
    streamlit run data_analyzer_app.py

The app opens in your browser (usually http://localhost:8501).
Try it with `sample_sales.csv` included in this folder.
"# dataanalyzer"
